# Table to Sheets AI (ระบบแปลงภาพถ่ายตารางบัญชีเป็น Google Sheets)

โปรแกรมเว็บแอปสำหรับแปลงภาพถ่ายตารางบัญชี (ยอดขาย / ค่าคอมมิชชั่น) เป็น Google Sheets และ Excel โดยเน้น:
1. **ความถูกต้องสูงสุด (100% Accuracy)**: มีระบบคำนวณผลรวมแถวและคอลัมน์อัตโนมัติ เทียบกับตัวเลขลายมือสรุปยอดด้านข้างและด้านล่าง
2. **ความเร็วสูง (High Speed)**: รองรับการประมวลผลผ่าน Gemini Flash API ไม่ต้องรอพิมพ์ช้าๆ ในแชท
3. **ใช้งานกับ Google Sheets ได้ใน 1 คลิก**: มีปุ่ม "📋 เปิดใน Google Sheets" ที่จะคัดลอกข้อมูลลงคลิปบอร์ดและเปิด `sheets.new` ให้ทันที เพียงกด `Cmd + V` วาง ข้อมูลจะลงตารางพร้อมใช้งาน

---

## วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกไฟล์ (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์:
```
table-to-sheets/start.command
```
ระบบจะเปิดเว็บแอปขึ้นมาที่เบราว์เซอร์ของคุณที่ `http://127.0.0.1:8000` โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal
```bash
cd table-to-sheets
../.venv/bin/python -m uvicorn server:app --host 127.0.0.1 --port 8765
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8765`

## การนำภาพถ่ายชุดใหม่ในอนาคตมาแปลง
1. ถ่ายภาพตารางให้ชัดเจน วางในโฟลเดอร์ที่ต้องการ
2. ในหน้าเว็บแอป กดปุ่ม **"ตั้งค่า Gemini API"** มุมขวาบน และใส่ API Key จาก [Google AI Studio](https://aistudio.google.com/apikey) (ฟรี)
3. ระบุโฟลเดอร์ แล้วกด **"แปลงทุกภาพด้วย AI"**
